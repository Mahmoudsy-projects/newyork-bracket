# دور پنجم — شبیه‌سازی آفلاینِ v1.5 (نه اجرای واقعیِ MT5)

این گزارش‌ها روی دیتای XChief دور چهارم ساخته شدند: DayNet_R آن دیتا از اول EOD-based بود (چون
اجرا با کد v1.2+v1.3 گرفته شده بود، قبل از v1.4) — یعنی دقیقاً معادل v1.5 است. فقط ستون
DayNet_R_Potential به‌صورت آفلاین (از رویِ MFE_Boxes موجود) بازسازی و اضافه شد تا
tools/compare_ground_truth.py واقعی (نسخه‌ی به‌روزشده‌ی v1.5) رویش تست شود.

نتیجه: DayNet_R رسمی ۸۷.۲٪/۹۲.۳٪/۸۶.۵٪ — بالای هدف ۸۰٪. **این هنوز یک اجرای واقعیِ MT5 با کد
v1.5 نیست** — فقط تأییدِ اینکه ابزار و فرمول درست کار می‌کنند. برای تأییدِ رسمی، باید فایل‌های
.mqh/.mq5 به‌روز از ریپو گرفته شوند، کامپایل و دوباره اجرا شوند.
